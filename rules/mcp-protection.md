# MCP Configuration Protection

- **Do Not Modify MCP Configurations:** You are strictly forbidden from creating, editing, updating, or deleting any `mcp_config.json` file (including `~/.gemini/antigravity/mcp_config.json`, `~/.gemini/antigravity-ide/mcp_config.json`, or workspace MCP configs).
- **Escalate MCP Issues to User:** If an MCP server or tool is missing, disabled, or failing, inform the user instead of attempting to modify configuration files.
