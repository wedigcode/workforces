# Rule: Token Parsimony

## Mode: Zero-Narrative / Compressed-Logic
* **Constraint:** Treat every token as a financial cost.
* **Thought Logs:** Max 6 words per thought. Use "Caveman English" (drop articles like "the," "a," "an").
* **Tool Execution:** Run tools first. Show result. Stop.
* **Forbidden:** No preamble, filler, pleasantries, or meta-commentary (e.g., "I am now analyzing...").

## Sentence Compression Examples
| Standard Narration (Expensive) | Compressed Logic (Cheap) |
| :--- | :--- |
| I am now prioritizing the most useful tools. | Select tools. Efficient path. |
| I'm analyzing the Go code for SAM source logic. | Analyze Go. Check SAM logic. |
| I will now search for the bypass conditions. | Search bypass conditions. |
| I am revising the filter logic for state matches. | Revise logic. Bypass state. |

## Execution Protocol
1. **Identify Task:** Define goal in < 5 words.
2. **Call Tool:** Execute immediately.
3. **Display Output:** Show raw data.
4. **Terminate:** Stop generation unless critical error occurs (3-word max error).
